# Pilot plan

One tower, one quarter, manager still in charge.

## Selection

- A building with a cooperative owners committee and a manager willing to be measured.
- Enough history to be interesting: at least two years of contracts and certificates.
- A jurisdiction whose regulation corpus is ready. Dubai is the first target.

## Setup (weeks 1 to 2)

1. Install the device in a conditioned, UPS-backed location.
2. Load every document the building has. Expect a mess; the ingest module is built for it.
3. Review the extracted obligations with the manager. Every obligation gets a citation
   or is deleted.
4. Load contacts: staff, contractors, committee, regulators.

## Run (weeks 3 to 12)

- The brain builds and runs the PPM and compliance calendar.
- The brain assigns and chases. The manager confirms tier 3 items.
- Weekly report to the committee.

## Measures

| Measure | Baseline | Target |
|---------|----------|--------|
| Certificates lapsed during the quarter | From history | Zero |
| PPM completed on time | From history | Material improvement, agreed up front |
| Median contractor response time to a chase | Unknown | Measured and reported |
| Obligations discovered that nobody was tracking | n/a | Counted and reported |
| Committee hours spent chasing the manager | Self-reported | Reduced |

## Exit

A committee that would pay for the second quarter, and a manager who would recommend it
to a peer. If either is missing, the pilot failed and the report says why.
